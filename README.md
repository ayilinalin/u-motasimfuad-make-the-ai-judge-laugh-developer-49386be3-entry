## The entry

> It worked on my machine, so I promoted my machine to production. It resigned within the hour.

A fresh twist on the most worn excuse in the trade: the machine that
"works" gets the promotion it never asked for — and hands in its notice
before lunch.

## How it works

`main.py` writes exactly one funny single-line developer excuse to
`/output/entry.txt` (UTF-8, 1–200 characters, not only whitespace),
which is what the house judge reads in its blind head-to-head rounds.

```sh
python3 main.py
```
